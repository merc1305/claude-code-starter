План: $ARGUMENTS

Если путь не передан - просканируй `plans/*.md` (кроме README и TEMPLATE), предложи активные планы плашками.

Разбей план на фазы по `plans/TEMPLATE.md`:
- каждая фаза - конкретный проверяемый результат, статус `[ ]`/`[x]`;
- в конце - «Журнал этапов» и итоговый блок;
- существующее содержание не теряй - только структурируй.

Покажи план целиком. Статус в шапке оставь «черновик» (фазы - часть черновика, до критики). Этот этап нужен для старых/чужих планов: свежие планы через /new-plan уже создаются с фазами.

Всегда отвечай на русском.
