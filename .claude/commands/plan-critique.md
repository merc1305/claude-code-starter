Выполни канон `prompts/methodology/plan-critique.md` для плана: $ARGUMENTS

Если путь не передан - просканируй `plans/*.md`, предложи плашками активные планы со статусом «черновик».

Follow the shared review canon: independent reviewers selected by risk, no fixed quota of agents or findings; judge each finding against evidence, record accepted changes and retain the owner approval boundary.

После принятия правок: внеси их в план, статус в шапке → «критика пройдена», строка в «Журнал этапов». Затем спроси плашками: «Best-check» (следующий этап) / «Стоп».
