# Вход в проект

Прочитай [общий процесс](docs/workflow.md) перед работой. Это единый источник правил для Claude Code, Codex и Kimi Code; не дублируй его здесь. `CLAUDE.md` только импортирует этот файл, поэтому правила проекта для всех агентов пиши сюда.

Начинай с текущей просьбы и доступного контекста, не с обязательного онбординга. Для продолжения найди действующий план и checkpoint. Локальные договорённости проекта сохраняй; конфликт требований явно обозначай владельцу.
